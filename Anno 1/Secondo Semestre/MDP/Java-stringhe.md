Al contrario dei tipi di dati primitivi, in Java le stringhe sono oggetti, quindi hanno metodi
# Metodi
- `.length()`
- `.toUpperCase()`
- `.toLowerCase()`
- `.indexOf(charOrString)`
	Torna l'indice della prima occorrenza del testo specificato
- `.charAt(index)`
	Torna il carattere all'indice specificato
- `.equals(charOrString)`
	Come ==
- `.trim()`
	Come `.strip()` in Python
- `.concat(charOrString)`
	Come + tra stringhe o char
